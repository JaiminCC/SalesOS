# Product configuration

Each organization has its own product catalog. The active session organization is the only tenant id the API uses. A body field named `organizationId` is rejected by validation.

## Product record

| Field | Rule |
|---|---|
| `id` | UUID, generated by the server |
| `organizationId` | Session tenant. Returned to the browser. Not accepted on create. |
| `name` | Required, trimmed |
| `productType` | `SOFTWARE`, `PHYSICAL`, `PROFESSIONAL_SERVICE`, `SUBSCRIPTION`, `DIGITAL`, `CUSTOM`, `OTHER` |
| `category` | Short label, may be empty |
| `shortDescription`, `detailedDescription` | Text |
| `website` | Empty or an `http`/`https` URL |
| `status` | `ACTIVE` or `ARCHIVED` |
| `tags`, `targetMarkets`, `languages` | String arrays |
| `currency` | Three-letter code. Omitted creates use the tenant currency from the identity connection. |
| `createdBy`, `updatedBy` | Session user |
| `createdAt`, `updatedAt`, `archivedAt` | Timestamps |

Creating a product also opens version 1 in `DRAFT` with an empty snapshot. The draft currency matches the product.

## Operations

| Action | Permission | Route |
|---|---|---|
| List, search, filter, details, activity | `products.read` | `GET /api/v1/products`, `GET /api/v1/products/:id`, `GET /api/v1/products/:id/activity` |
| Create, edit, duplicate, archive, restore | `products.write` | `POST /api/v1/products`, `PATCH /api/v1/products/:id`, `POST .../duplicate`, `POST .../archive`, `POST .../restore` |

List query parameters are `q`, `productType`, `status`, `page`, and `pageSize`. Search matches name, category, and short description, case-insensitive. The default status filter is `ACTIVE`. A product in another organization is `404`, because row-level security hides it.

Duplicate copies the catalog fields and the current draft or published snapshot into a new product and a new draft. Archive sets `ARCHIVED` and `archivedAt`. Restore clears both.

Activity is the tenant audit stream for that product id: creates, updates, version transitions, uploads, approvals, and deletions.

## Organization defaults

`GET /api/v1/product-defaults` and `PUT /api/v1/product-defaults` store positioning, pricing, and `knowledgeRetentionDays` (0 through 3650) for the active organization.

Inheritance, applied by `mergeProductContext` when a version is previewed:

- A non-empty product string replaces the organization string.
- A non-empty product array replaces the organization array.
- An empty product field keeps the organization value.
- Pricing is one object. The organization pricing object is used only while the product pricing is still the untouched default: model `CUSTOM_QUOTE`, `visible` false, empty summary, and no tiers.
- Once the product sets a model, a summary, a tier, or visibility, the whole product pricing object is used.
- ICP definitions are not inherited. They belong to the product version.

Free-text positioning does not grant permission to send mail, change a role, or skip an approval. The positioning screen states that.

## Example

```http
POST /api/v1/products
Content-Type: application/json
x-salesos-csrf: 1
```

```json
{
  "name": "Field Kit",
  "productType": "PHYSICAL",
  "category": "Operations",
  "shortDescription": "Kit for on-site work",
  "currency": "USD",
  "tags": ["field"],
  "targetMarkets": ["Regional"],
  "languages": ["en"]
}
```

```json
{
  "data": {
    "id": "8c1b1f2e-7a0d-4c1e-9b2a-0a6d5e4f3c2b",
    "organizationId": "11111111-1111-4111-8111-111111111111",
    "name": "Field Kit",
    "productType": "PHYSICAL",
    "status": "ACTIVE",
    "draftVersionId": "2b7e9a10-6c4d-4e8f-a1b2-3c4d5e6f7081"
  },
  "meta": { "requestId": "req_01" }
}
```

Success responses use `{ data, meta: { requestId } }`. Errors use `{ error: { code, message }, meta: { requestId } }`. Permission denial is `403` `FORBIDDEN`. A missing or foreign product is `404` `NOT_FOUND`.

## Startup

```sh
pnpm infra:up
pnpm db:setup
pnpm dev:api
pnpm dev:worker
pnpm dev:web
```

`infra/docker-compose.yml` uses `pgvector/pgvector:pg16`. Sign in, open Products & Services, and use the active organization in the sidebar. Command Center, campaigns, inbox, and WhatsApp remain simulated.
