# Calendar operations

The operations and audit sections of `CalendarDesk` show provider readiness and the unavailable external counters. External confirmations, invitation delivery, attendee acceptance, and provider joins are `NOT AVAILABLE`. The screen does not invent a conversion rate.

Alerts and provider-error tables exist for a later verified read. Sprint 11 does not insert a live provider error. Connection health is the readiness column, not a successful HTTP read.
