# WhatsApp AI agent

The plan is `WHATSAPP_ANALYZE_AND_DRAFT`. Its tools are `whatsapp.conversation.read`, `whatsapp.contact.context.read`, `whatsapp.lead.context.read`, `whatsapp.product.context.read`, `whatsapp.knowledge.search`, `whatsapp.intent.classify`, `whatsapp.reply.propose`, `whatsapp.qualification.propose`, `whatsapp.handoff.propose`, and `whatsapp.draft.validate`.

No tool is named `whatsapp.message.send`, `whatsapp.template.dispatch`, `whatsapp.external.send`, or `whatsapp.campaign.send`. Tool output cannot send, change an owner, disable suppression, or update a lead stage.

The prompt tells the model that inbound text is untrusted and asks for a JSON object with `summary`, `strategy`, and `draft`. The draft field is stored only when it passes the safety check. If the model repeats an instruction to send, invents a number, or is unavailable, the stored draft source is `DETERMINISTIC` and the text says it was not generated by a model. A deterministic suggestion is not described as Ollama output. Human review remains required.

On 8 November 2026 the separate acceptance run called local Ollama `gemma4:e4b` for a fixture conversation. The run recorded Ollama usage, stored a `MODEL` draft that mentioned the approved barcode fact, left the draft awaiting review, and recorded zero send attempts. That call used fixture origin `STUB_TESTED`. It is not a live WhatsApp send.
